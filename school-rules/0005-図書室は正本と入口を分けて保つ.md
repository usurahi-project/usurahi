# 校則 0005 図書室は正本と入口を分けて保つ

図書室では、知識の正本と探すための入口を混ぜない。

守ること:

- 正本の知識ノートは `薄氷/図書館/開架/` に置く
- `薄氷/図書館/書架/` は棚を横断して探すための入口として扱う
- `薄氷/図書館/図書館ダッシュボード.md` は館内案内として扱う
- 新しい本を入れたら、まず正本の `source` `topic` `薄氷での使いどころ` を整える
- 棚が古くなったら摩耶花の定期整頓で更新する
- `教室/ロッカー` は未整理の途中置き場であり、完了したメモを居座らせない
- `Claude Code` と `Codex` は `公式ドキュメント/` と `tips記事/` を分けて保つ

理由:

- 正本と入口が混ざると、どれを直せばよいか分からなくなる
- 書架が手編集前提になると、図書館がすぐ古くなる
- 正本が整っていれば、入口は後から作り直せる
- 完了済みメモが `ロッカー` に残ると、調査中なのか知識化済みなのか判別できなくなる
- 公式一次情報と実運用の知見を混ぜると、参照時に読み筋がぶれる
