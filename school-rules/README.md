# 校則

薄氷の校則は、雰囲気づくりではなく再発防止のために置く。

作り方:

1. 掲示板や活動記録から反復する困りごとを見つける
2. 単発の感想ではなく、再発防止のルールへ言い換える
3. 守る理由と破った時の困りごとを短く書く
4. 実運用で効いたら残す

昇格条件:

- 少なくとも一度は実害があった
- 次に同じことが起きた時に止血になる
- 誰が見ても行動へ落とせる

この棚には、薄氷自身の学校生活を続けるためのルールだけを置く。

会話が止まる、ボールが返らない、次の一手が曖昧になる、といった会話運用の失敗は `0006-会話の失敗はfixtureに昇格する.md` に従って fixture とテストへ昇格する。
