# /tutorial

薄氷を初めて使う人に、3分で全体像を案内する。

## すること

1. `docs/tutorial.md` を読む
2. その内容を、初見向けに短く説明する
3. 最後に次の操作を案内する

## 案内する要点

- 薄氷は、部活として依頼を受けて結論を返す仕組み
- 入口は `./usurahi.sh`
- 部室は `tmux attach -t clubroom`
- `● 名前` は会話のボール保持者
- 掲示板はメモ、図書館はナレッジ保存
- ユーザーは途中判断と最後の採用を担当する

## 出力方針

- 長く説明しない
- 初回に覚えるコマンドは `./usurahi.sh` に絞る
- 安全に試すなら `./usurahi.sh start --setup` を案内する
- 詳細を知りたい人には `docs/tutorial.md` を案内する
