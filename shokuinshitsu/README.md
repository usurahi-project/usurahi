薄氷における `職員室` は、部活そのものではなく、薄氷を運営するための資料置き場である。

初めて触る人は、まず [README.md](../README.md) を読む。
ここはその一段奥にある詳細資料置き場である。

ここには次の3種類を置く。

- 使い方
- 世界観と役割
- 技術設計
