# 薄氷 3分チュートリアル

初めて触る人は、まずこのページだけ読めばよい。

## 1. 薄氷とは

薄氷は、学園アニメ的な部活動の流れでソフトウェア開発を進める仕組み。
ユーザーが依頼を持ち込み、部員たちが議論し、実装し、最後に「今の部としての結論」を返す。

最短回答ではなく、複数の視点が混ざった結論を作ることを大事にする。

## 2. まず覚える入口

```bash
./usurahi.sh
```

迷ったらこれだけでよい。
受付から、会議・部室・掲示板・図書館・状態確認へ進める。

## 3. 主な場所

- 受付: `./usurahi.sh`
- 部室: `tmux attach -t clubroom`
- 掲示板: あとで扱う論点やメモを置く
- 図書館: URLやナレッジを残す
- ダッシュボード: 学校運営の状態を見る

## 4. 主な人

- える: 受付、背景掘り、結論化
- ハルヒ: 方向づけ、停滞打破
- 折木: 論点抽出、最小案、最小修正
- キョン: 現実チェック、出口確認
- 長門: 技術判断、実装
- 摩耶花: 図書館の整理

全員が毎回出る必要はない。
その時の依頼に必要な人が前に出る。

## 5. 会議中に見るもの

```bash
tmux attach -t clubroom
```

部室では、会話のボールを持っている人が `● 名前` で表示される。
黒板には `phase`、ボール保持者、進行役、次の一手、完了条件が出る。

## 6. あなたの役割

ユーザーは依頼を持ち込み、途中で判断を返し、最後に採用を決める人。

薄氷側が迷っている時は、あなたに判断を返す。
あなたは全部を指示しなくてよい。
ただし、方向や採用可否は最後に決める。

## 7. 最初の一手

```bash
./usurahi.sh tutorial
./usurahi.sh start
```

使い方だけ見たい時は `tutorial`。
すぐ始める時は `start`。
